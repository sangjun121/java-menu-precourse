# 점메추 - [BE] 조상준

# 1. 기능 명세서

## 0. 부트스트랩
- [x] 기본 카테고리 초기화하여 저장한다.
- [x] 기본 메뉴를 초기화하여 저장한다.

## 1. 입력기능
- [x] 코치의 이름을 입력 받는다.
  - [x] 검증. 코치의 이름은 최소 2자에서 최대 4자이다.
  - [x] 검증. 코치는 최소 2명에서 5명까지 가능하다.
- [ ] 각 코치가 못먹는 메뉴를 입력한다.
  - 예: 토미(이)가 못 먹는 메뉴를 입력해 주세요.

## 2. 점심 메뉴 추천
- 아래 기능을 1사이클로 5회(월~금) 반복한다.

### 2-1. 카테고리 선정 
- [ ] 각 요일의 카테고리를 랜덤으로 배정한다.
- [ ] 해당 카테고리가 앞선 요일에 2회 이상 등장한 경우, 카테고리를 재추첨한다.
  - 검증. 한 주에 같은 카테고리는 최대 2회까지만 고를 수 있다.

## 2-2. 메뉴
- 아래 기능을 모든 코치에 대해 반복한다.
- [ ] 카테고리에 해당하는 각 메뉴를 랜덤으로 선정한다.
- [ ] 해당 메뉴가 코치의 못 먹는 메뉴에 있는 경우 다시 추천한다.
- [ ] 앞선 요일에 같은 메뉴가 있는 경우 다시 추천한다.

## 출력 기능
- [ ] 메뉴 추천 결과를 출력한다.
